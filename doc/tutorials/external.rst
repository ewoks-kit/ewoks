More tutorials
==============

* `ewoksorange <https://ewoksorange.readthedocs.io/>`_ : create and execute :term:`workflows <Workflow>` with a desktop GUI
* `ewoksweb <https://ewoksweb.readthedocs.io/>`_: web frontend to create, visualize and execute :term:`workflows <Workflow>`
* `ewokscore <https://ewokscore.readthedocs.io/>`_ : create :term:`workflows <Workflow>` and implement :term:`tasks <Task>` in Python
* `Ewoks training <https://ewoksfordevs.readthedocs.io/>`_ on :term:`task <Task>` implementation, :term:`workflow` creation/execution and job scheduling.
* Tutorial on `Ewoks for Online Data Processing <https://gitlab.esrf.fr/workflow/ewokstutorials/ewokswithblissdata>`_
  with :term:`blissdata` which is a python library to store and access
  scientific data during and after experiment at large-sclae facilities like `ESRF <https://www.esrf.eu/>`_.
